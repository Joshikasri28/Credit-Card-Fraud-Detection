# Credit Card Fraud Detection

## Overview

This project uses Machine Learning techniques to detect fraudulent credit card transactions. It analyzes transaction data, performs data preprocessing, and applies classification algorithms to identify suspicious activities accurately.

## Tech Stack

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib

## Features

* Data Preprocessing
* Fraud Detection
* Machine Learning Models
* Data Visualization
* Model Evaluation
